# Sudoku
##  Sobre o projeto 👩🏻‍💻
Esse projeto foi feito a partir de um bootcamp que participei, é basicamente um jogo de Sudoku e foi a primeira vez que trabalhei com UI em Java e foi bem interassante usar o Swing, o Java não para de me surpreender e mostrar o quando é uma linguagem bem completa.
## Como rodar esse projeto?
Esse projeto ainda precisa de variáveis de ambiente setadas e apenas cria um mesmo jogo. Em breve irei realizar melhorias e a criação randomica de jogo. 
<strike>sudoku é um pouco complicado de organizar as regras</strike>.🫠​
